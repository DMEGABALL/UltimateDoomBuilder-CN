编译 GZDoom Builder

必需的软件：

  • Visual C# 2008 Express Edition 或更新版本，并支持 .net Framework 3.5。你可以从 http://msdn.microsoft.com/vstudio/express/ 免费下载它。或者，你也可以使用支持 .net Framework 3.5 的 Visual Studio 2008 或更新版本。

可选的软件：

  • Git 命令行客户端（https://git-scm.com/）。
  • TortoiseGit（https://tortoisegit.org/）。
  • 7-zip 压缩软件（www.7-zip.org）。
  • Inno Setup 5 或更新版本（http://www.jrsoftware.org/isinfo.php）。
  • Microsoft HTML Help 编译器（http://www.microsoft.com/en-us/download/details.aspx?id=21138）。
  • SlimDX Developer SDK（http://slimdx.org/download.php）。
  • DirectX SDK（https://www.microsoft.com/en-us/download/details.aspx?id=6812）。

获取源代码：

GZDoom Builder 的源代码托管在 GitHub 上（https://github.com/m-x-d/GZDoom-Builder）。

快速入门指南：

本指南假定你使用的是 Visual Studio 2008 / Visual C# 2008 Express Edition 以及 TortioseGit。
  1. 创建一个空文件夹，在其上单击右键，然后从上下文菜单中选择“GIT Clone...”。
  2. 在“URL”字段中输入“https://github.com/m-x-d/GZDoom-Builder.git”，单击“确定”，然后等待源代码下载完成。
  3. 在 Visual Studio 中打开“Builder.sln”，确认它可以编译并运行（单击绿色的“Play”按钮，或按 F5）。
    • 如果 Visual Studio 报告 Builder 项目中缺少 SlimDX 引用，你需要手动重新添加它。操作方法：在“解决方案资源管理器”的“引用”中删除 SlimDX，右键单击 Builder 项目并选择“添加引用”。在“.NET”选项卡中，选择 SlimDX（.net 2.0，x86 版本）。
    • 你可以忽略关于缺少 JetBrains.Profiler.Core.Api 引用的警告。除非你选择启用了性能分析器的生成目标（或者你可以使用 dotTrace Performance，如果你有权限访问它），否则一切都应该能正常生成。
  4. 如果你打算将所做更改提交到 GZDoom Builder 的主仓库，建议先在 GitHub 上 fork GZDoom Builder，进行更改，然后提交 Pull Request。

批处理文件：

GZDB 源代码附带了若干批处理文件，可用于自动编译和打包编辑器。首次运行某个批处理文件之前，请务必打开它，并检查保存软件路径的变量是否指向正确的目录。这些变量总是位于文件顶部附近、信息块之后。
  • Clean Rebuild.bat - 删除项目缓存文件，然后以 Release 模式编译项目。
    需要 Visual C# Express Edition / Visual Studio。

  • Compile Help.bat - 编译“Build\Refmanual.chm”。帮助源文件位于“Help”目录中。
    需要 Microsoft HTML Help 编译器。

  • Make Release.bat - 删除项目缓存文件，将项目版本号设置为与最新的 SVN 修订版本一致，以 Release 模式编译项目，生成“Build\Changelog.txt”，编译“Build\Refmanual.chm”，创建安装程序并将其放入“Release”文件夹。
    需要 Git 命令行客户端、Visual C# Express Edition / Visual Studio、Microsoft HTML Help 编译器以及 Inno Setup 5。

  • Make GIT Build.bat - 删除项目缓存文件，将项目版本号设置为与 master 分支中的提交数量一致，以 Release 模式编译项目，生成“Build\Changelog.txt”，编译“Build\Refmanual.chm”，将该构建打包为 7-zip 压缩包并将其放入“GIT_Build”文件夹。
    需要 Git 命令行客户端、Visual C# Express Edition / Visual Studio、Microsoft HTML Help 编译器以及 7-zip 压缩软件。
