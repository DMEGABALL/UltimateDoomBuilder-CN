游戏配置 - 扇区设置

generalizedsectors (boolean)
设置为 true 以支持泛化扇区效果。这会使 gen_sectortypes 结构成为必需。默认值为 false。

sectorflags (structure) - 仅 GZDB，仅 UDMF。
列出可在扇区上设置的选项。

ceilingportalflags (structure) - 仅 GZDB，仅 UDMF。
列出可在扇区天花板传送门上设置的选项。

floorportalflags (structure) - 仅 GZDB，仅 UDMF。
列出可在扇区地板传送门上设置的选项。

sectorrenderstyles (structure) - 仅 GZDB，仅 UDMF。
列出可在扇区上设置的渲染样式。

示例： 

        
sectorrenderstyles
{
	translucent = "Translucent";
	add = "Additive";
}

sectorportalrenderstyles (structure) - 仅 GZDB，仅 UDMF。
与 sectorrenderstyles 相同，但用于地板/天花板传送门。

sectorbrightness (structure)
此结构向 Doom Builder 提供一组最常见的扇区亮度级别。Doom Builder 将使用这些级别来快速增加/减少亮度。该结构必须包含亮度级别的数字设置名称。这些设置不需要值，任何值都会被 Doom Builder 忽略。

示例： 
sectorbrightness
{
	96;
	64;
	32;
	0;
}

gen_sectortypes (structure)
泛化扇区类型在此结构中描述。当 generalizedsectors 设置为 true 时，此结构是必需的。每个选项都应有一个结构。结构的名称显示为选项说明。每个选项结构应包含一个用于可用选项的设置。设置名称必须是数值，该数值会与其他选项中所选项的值一起加到最终的扇区效果值上（因此最终的扇区效果值是每个选项中所选项的总和）。该设置必须具有包含要显示的选项说明的字符串值。

示例： 
gen_sectortypes
{
	secret
	{
		0 = "No";
		128 = "Yes";
	}
	
	friction
	{
		0 = "Disabled";
		256 = "Enabled";
	}
	
	wind
	{
		0 = "Disabled";
		512 = "Enabled";
	}
}

sectortypes (structure)
这是用户可从中选择的所有可用扇区效果的简单列表。设置名称必须是数字（扇区效果编号），值必须是包含要显示的说明的字符串。

示例： 
sectortypes
{
	0 = "Normal";
	1 = "Light Blinks (randomly)";
	2 = "Light Blinks (2 Hz)";
	3 = "Light Blinks (1 Hz)";
	4 = "Damage -10 or 20% health and Light Blinks (2 Hz)";
	5 = "Damage -5 or 10% health";
	7 = "Damage -2 or 5% health";
	8 = "Light Glows (1+ sec)";
	9 = "Secret";
}
