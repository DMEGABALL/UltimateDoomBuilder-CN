游戏配置 - 物件设置

常规设置：

defaultthingflags (structure)
此项定义了插入第一个新物件时，其默认标志应当是什么。在使用数值物件标志的地图格式中，此结构中的设置应为要设置的数值标志。在使用命名标志的地图格式中，这些设置必须是所要设置的标志的名称。设置的值是可选的，并且会被 Doom Builder 忽略。

数值标志示例： 

defaultthingflags
{
  1;
  2;
  4;
  32;
}

命名标志示例： 
defaultthingflags
{
  skill1;
  skill2;
  skill3;
  single;
  coop;
}

thingrenderstyles (structure) - 仅 GZDB，仅 UDMF。
列出可在物件上设置的渲染样式。

示例： 
        
thingrenderstyles
{
  normal = "Normal";
  translucent = "Translucent";
  soultrans = "Translucent (Lost Soul)";
  translucentstencil = "Translucent (stencil)";
  add = "Additive";
  subtract = "Subtractive";
  stencil = "Stencil";
  fuzzy = "Fuzzy";
  optfuzzy = "Fuzzy/Shadow (uses r_drawfuzz CVAR)";
  none = "None";
}

物件分类定义：
这些设置可用于物件分类定义的内部。
说明：在 GZDB 中物件分类可以嵌套。

sorted (integer) [0 .. 1]
设为 1 时，此分类中的项目将按标题排序。

物件与物件分类定义：
这些设置既可用于物件分类定义，也可用于物件定义。

color (integer) [0 .. 19]
设置此分类中物件所使用的颜色。
可能的值为：
  •   0 - █ 深灰色；
  •   1 - █ 蓝色；
  •   2 - █ 绿色；
  •   3 - █ 青色；
  •   4 - █ 红色；
  •   5 - █ 洋红色；
  •   6 - █ 棕色；
  •   7 - █ 灰色；
  •   8 - █ 浅灰色；
  •   9 - █ 浅蓝色；
  • 10 - █ 浅绿色；
  • 11 - █ 浅青色；
  • 12 - █ 浅红色；
  • 13 - █ 浅洋红色；
  • 14 - █ 黄色；
  • 15 - █ 白色；
  • 16 - █ 粉色；
  • 17 - █ 浅橙色；
  • 18 - █ 浅棕色（默认）；
  • 19 - █ 橙色；

arrow (integer) [0 .. 1]
设为 1 时，物件的朝向将在经典模式与视觉模式中显示为箭头。

renderstyle (string)
设置此分类或物件的渲染样式。参见 zdoom.org/wiki/Actor_properties#RenderStyle。
默认值为 "Normal"。

alpha (decimal) [0.0f .. 1.0f]
设置此分类或物件的 alpha 值。
默认值为 "1.0f"。

title (string)
设置此分类或物件的标题。

sprite (string)
设置渲染此物件或此分类中的物件时所使用的精灵图形。这应是带完整名称的精灵名（不含文件扩展名），例如 "CPOSA2"。
你也可以使用「Sprites」目录中的图像：在图像名（不含扩展名）前加上 "internal:" 前缀，例如 "internal:Actor"。

width (integer)
设置渲染物件时所使用的宽度（经典模式与视觉模式）。
默认值为 10。

height (integer)
设置渲染物件时所使用的高度（经典模式与视觉模式）。
默认值为 20。

hangs (integer) [0 .. 1]
设为 1 时，在视觉模式中该物件将对齐到天花板，而不是地板。

blocking (integer) [0 .. 2]
设置物件的阻挡模式。此值用于检查卡住的物件。
可能的值为：

  • 0 - 不阻挡。
  • 1 - 完全阻挡。
  • 2 - 真实高度（True-Height）。
error (integer) [0 .. 2]
设置用于此物件的卡住物件错误检查模式。
可能的值为：
  • 0 - 不检查此物件。
  • 1 - 检查物件是否位于地图几何体之外。
  • 2 - 检查物件是否位于地图几何体之外，或是否卡在另一个物件内部。
默认值为 1。

fixedsize (boolean)
设为 true 时，物件将在经典模式与视觉模式中渲染为无尺寸。

fixedrotation (boolean) - 仅 GZDB。
设为 true 时，在使用编辑选择模式旋转物件时，物件的朝向不会被改变。

absolutez (boolean)
设为 true 时，在视觉模式中物件的垂直位置将被用作绝对值，而不是相对于地板/天花板的距离。

spritescale (decimal)
可用于修改视觉模式中渲染的精灵缩放。
默认值为 "1.0f"。

物件定义：
这些设置可用于物件定义的内部。

locksprite (boolean) - 仅 GZDB。
设为 true 时，即使此物件的 DECORATE 角色定义中包含不同的精灵，也将使用游戏配置中设置的精灵。

class (string) - 仅 GZDB。
设置与此物件对应的 DECORATE 类名。内部用于将模型和动态光源附加到给定物件，以及在 DECORATE 解析器中查找要继承的角色类。
示例： 
3001
{
  title = "Imp";
  sprite = "TROOA2A8";
  class = "DoomImp";
}

locksprite (boolean) - 仅 GZDB。
设为 true 时，即使此物件的 DECORATE 角色定义中包含不同的精灵，也将使用游戏配置中设置的精灵。

flagsrename (structure) - 仅 GZDB。
允许为每种受支持的地图格式中的特定物件指定自定义标志名称。
示例： 
9998
{
  title = "Actor enters sector";
  class = "SecActEnter";
  flagsrename
  {
    DoomMapSetIO
    {
      8 = "Monsters activate";
    }
    HexenMapSetIO
    {
      8 = "Monsters activate";
      16 = "Projectiles activate";
      8192 = "Players can't activate";
      16384 = "Activate once only";
    }
    UniversalMapSetIO
    {
      ambush = "Monsters activate";
      dormant = "Projectiles activate";
      strifeally = "Players can't activate";
      standing = "Activate once only";
    }
  }
}
