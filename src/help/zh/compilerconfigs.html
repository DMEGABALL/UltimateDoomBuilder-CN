关于编译器配置

在编辑器中使用脚本编译器和节点构建器（nodebuilder）需要编译器配置。
编译器配置从放置在 "Compilers" 目录或其子目录中的 *.cfg 文件加载。

脚本编译器配置：

典型的脚本编译器配置由单个块组成：

"Compilers" 块：

定义编译器使用哪些文件。 名为 "program" 的设置定义要运行哪个 .exe。 "interface" 设置定义用于处理和错误反馈的内部接口（目前唯一有效的值是 "AccCompiler"）。其余设置都是所需的文件（设置名称无关紧要）。

示例： 

compilers
{
	zdoom_acc
	{
		interface = "AccCompiler";
		program = "acc.exe";
		zcommon = "zcommon.acs";
		zdefs = "zdefs.acs";
		zspecial = "zspecial.acs";
		zwvars = "zwvars.acs";
	}
}

节点构建器配置：

典型的节点构建器配置由两个块组成：

"Compilers" 块：

定义编译器使用哪些文件。
名为 "program" 的设置定义要运行哪个 .exe。
"interface" 设置定义用于处理和错误反馈的内部接口（目前唯一有效的值是 "NodesCompiler"）。

示例： 

compilers
{
	zdbsp
	{
		interface = "NodesCompiler";
		program = "zdbsp.exe";
	}
}

"Nodebuilders" 块：

定义为 "compilers" 块中节点构建器提供的各种预设（随后你可以在游戏配置窗口中选择使用哪些）。注意：此处定义的节点构建器配置键名必须在所有节点构建器中唯一！ 建议键名以编译器名称开头，后接下划线和一个特定名称。"compiler" 设置必须引用一个已存在的编译器，但不一定非得是同一配置文件中定义的编译器。

"parameters" 设置支持以下通配符：
  • "%FI" - 输入文件路径。
  • "%FO" - 输出文件路径。
示例： 
nodebuilders
{
	zdbsp_normal
	{
		title = "ZDBSP - Normal (no reject)"; // 在游戏配置窗口中显示的名称
		compiler = "zdbsp"; // 必须与 "compiler" 块中定义的节点构建器块名称匹配
		parameters = "-c -o%FO %FI"; // 命令行参数
	}
}
