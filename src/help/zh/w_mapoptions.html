地图选项窗口

此对话框窗口可让你更改一些应用于整张地图以及地图加载方式的选项。你可以从“编辑”菜单访问它，或使用默认按键 F2。在顶部，你可以选择编辑此地图时要使用的游戏配置。请注意，切换到不同文件格式的配置可能会导致地图中的信息丢失，甚至可能损坏地图。游戏配置字段下方是关卡名称字段。你可以在这里输入用于在 WAD 文件中存储地图的 lump 名称。Doom 1 地图的关卡名称示例可以是 E2M3，表示该地图属于第 2 章第 3 关。Doom 2 地图的示例是 MAP03，即第 3 关。

资源

资源区域可让你指定编辑此地图时加载哪些资源。仅为此文件严格加载 P_START 与 P_END 之间的 patch复选框作用于你正在编辑的 wad 文件（即你的地图所在的文件）。勾选此项后，Doom Builder 会严格按照 id Software 的本意，仅从 P_START 与 P_END 这两个 lump 之间加载 patch lump 来解决贴图 patch 冲突，但大多数源端口并不需要这样做（因此，较旧的地图会有不在 P_START 与 P_END 之间的贴图 patch lump）。

在资源列表中，你可以看到所有将被加载的资源。Doom Builder 会把来自游戏配置的项以灰色显示在列表顶部，因为它们总是最先加载。你可以根据游戏配置在游戏配置窗口中更改所加载的资源。你可以拖动资源项（来自游戏配置的项除外）来更改它们的顺序。另请参见资源选项窗口。
