DECORATE 键

GZDoom Builder 包含一个 DECORATE 解析器，用于从自定义角色中获取相关信息（如编辑器编号、Radius、Height、Scale 等）。


全局定义（仅 GZDB）：
可以在全局 DECORATE 块中插入以特殊注释形式出现的键，来传递附加信息：

//$GZDB_SKIP
DECORATE 解析器在遇到此注释后将停止解析文件。这可用于通过跳过不包含可放置角色定义的文件来加速解析过程。


角色定义：
可以在角色的声明块中插入以特殊注释形式出现的键，来传递附加信息：

//$Angled - 仅 GZDB。
//$NotAngled - 仅 GZDB。
指定方向是否重要（是否带有角度）。不区分方向的物件将以不带方向箭头的形式表示。

//$Category <category>
指定它应被归入哪个分类（怪物、武器等）。默认情况下，未在配置文件中标识的自定义角色将被放入 Decorate 分类。
GZDoom Builder 支持使用反斜杠分隔符的层级子分组。例如，//$Category "Decorations/Tech" 会将角色放入 "Decorations" 组的 "Tech" 子分组中。

//$Sprite <sprite>
指定在编辑器中用哪个精灵来表示该角色。默认情况下，未在配置文件中标识的自定义角色将使用它在角色定义中找到的第一个合适精灵：先依次尝试 Idle、See、Inactive、Spawn 这些状态，如果全部失败，则使用第一个已定义的状态。因此，此键对无状态的角色定义特别有用。请记住，此精灵名必须与 WAD 中的图像匹配（也就是说，如果你 WAD 中的精灵名为 JUNKA0D0，就必须写 JUNKA0D0，JUNKA0 不行）。

//$Title <title>
指定赋予该角色的名称。默认情况下，未在配置文件中标识的自定义角色将使用 Tag 属性，如果该属性不存在，则默认为类名。

//$IgnoreRenderstyle - 仅 GZDB。
编辑器将忽略 DECORATE 的 "RenderStyle" 属性。当你希望在视觉模式中看到不可见角色的精灵时会很有用。

//$ArgN <name> - 仅 GZDB。
允许覆盖此角色的默认参数名称。

//$ArgNDefault <integer> - 仅 GZDB。
允许设置此参数的默认值。此属性必须与 "//$ArgN" 属性配合使用。

//$ArgNTooltip <text> - 仅 GZDB。
允许指定为此参数显示的提示文本。可以使用换行符（"\n"）来格式化文本。此属性必须与 "//$ArgN" 属性配合使用。
参数提示也可以在游戏配置中为物件和线段设置。

//$ArgNType <integer> - 仅 GZDB。
允许为此参数指定参数类型。此属性必须与 "//$ArgN" 属性配合使用。

//$ArgNRenderStyle <string> - 仅 GZDB。
允许指定用于显示此参数值的渲染形状。支持的值有：

  • "Rectangle"。参数值用作矩形尺寸。
  • "Circle"。参数值用作圆形半径。
渲染形状可通过"切换事件线（Toggle Event Lines）"动作/菜单按钮切换。
此属性必须与 "//$ArgN" 属性配合使用。

//$ArgNRenderColor <integer> - 仅 GZDB。
允许指定渲染形状所使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，渲染形状将使用事件线编辑器颜色。
此属性必须与 "//$ArgN" 和 "//$ArgNRenderStyle" 属性配合使用。

//$ArgNMinRange <integer> - 仅 GZDB。
允许指定渲染形状的最小范围。
默认情况下，最小范围形状将使用指示编辑器颜色。
此属性必须与 "//$ArgN" 和 "//$ArgNRenderStyle" 属性配合使用。

//$ArgNMinRangeColor <integer> - 仅 GZDB。
允许指定渲染最小范围形状时使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，最小范围形状将使用指示编辑器颜色。
此属性必须与 "//$ArgN"、"//$ArgNRenderStyle" 和 "//$ArgNMinRange" 属性配合使用。

//$ArgNMaxRange <integer> - 仅 GZDB。
允许指定渲染形状的最大范围。
默认情况下，最大范围形状将使用指示编辑器颜色。
此属性必须与 "//$ArgN" 和 "//$ArgNRenderStyle" 属性配合使用。

//$ArgNMaxRangeColor <integer> - 仅 GZDB。
允许指定渲染最大范围形状时使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，最大范围形状将使用指示编辑器颜色。
此属性必须与 "//$ArgN"、"//$ArgNRenderStyle" 和 "//$ArgNMaxRange" 属性配合使用。

//$ArgNEnum <string or structure> - 仅 GZDB。
允许为此参数指定枚举。这可以是游戏配置中定义的枚举名称，也可以是显式的枚举定义。此属性必须与 "//$ArgN" 属性配合使用。

//$Color <color index> - 仅 GZDB。
允许覆盖此角色的分类颜色。可能的值为：
  •   0 - █ 深灰色；
  •   1 - █ 蓝色；
  •   2 - █ 绿色；
  •   3 - █ 青色；
  •   4 - █ 红色；
  •   5 - █ 洋红色；
  •   6 - █ 棕色；
  •   7 - █ 灰色；
  •   8 - █ 浅灰色；
  •   9 - █ 浅蓝色；
  • 10 - █ 浅绿色；
  • 11 - █ 浅青色；
  • 12 - █ 浅红色；
  • 13 - █ 浅洋红色；
  • 14 - █ 黄色；
  • 15 - █ 白色；
  • 16 - █ 粉色；
  • 17 - █ 浅橙色；
  • 18 - █ 浅棕色（默认）；
  • 19 - █ 橙色；
//$Obsolete <reason> - 仅 GZDB。
将此物件标记为过时。"Check obsolete things" 地图分析模式检查会发现它，并且它将在物件属性窗口和物件信息面板中被标记出来。

注意：如果你希望该角色在 Doom Builder 中显示，即使它替换的是标准 Doom 角色，也最好在角色定义后写上 Doom 编辑器编号。

示例：
Actor ChexShield : ResistanceRune replaces ResistanceRune 5104
{
  //$Category "Pickups/Chex Powerups"
  //$Sprite ARMXA0
  //$IgnoreRenderstyle
  //$Title "Chex Shield"
  //$Color 12
  //$NotAngled
  //$Obsolete "那是一个奇怪的强化道具。考虑把它换成别的东西……"
  
  //$Arg0 "重生延迟"
  //$Arg0ToolTip "正值以 tic 为单位指定延迟。\n负值以秒为单位。"
  
  //$Arg1 "枚举示例 1"
  //$Arg1ToolTip "配置枚举示例"
  //$Arg1Type 11
  //$Arg1Enum "keys"
	
  //$Arg2 "枚举示例 2"
  //$Arg2ToolTip "显式枚举示例"
  //$Arg2Type 11
  //$Arg2Enum { 1 = "第一个选项"; 2 = "第二个选项"; 667 = "选项 667"; }
  
  //$Arg3 "半径"
  //$Arg3Type 23
  //$Arg3Default 32
  //$Arg3RenderStyle "Circle"
  //$Arg3RenderColor #ff00ff
  //$Arg3MinRange 32
  //$Arg3MaxRange 512
  //$Arg3MinRangeColor #0000ff
  //$Arg3MaxRangeColor #ff0000
	
  //$Arg4 "高度"
  //$Arg4Type 24
  //$Arg4Default 64
  

  Height 44
  Radius 26
  RenderStyle None
  Inventory.PickupMessage "Picked up the energized Chex armor!"
  

  States
  {
    Spawn:
      ARMX A 1
      Loop
  }
}

//$GZDB_SKIP
actor SuperGiantImpBall : DoomImpBall
{
  Scale 8.0
  Damage 30
}


分类定义（仅 GZDB）：

可以使用 #region / #endregion 块在 DECORATE 中定义物件分类。区域名称用作物件分类标题。角色块中的 "//$Category" 定义会覆盖这些设置。可以在 #region / #endregion 块中插入以特殊注释形式出现的键，来传递附加信息（这些键以略有不同的语法复刻了游戏配置的物件分类属性）：

//$Sorted (integer) [0 .. 1]
设为 1 时，此分类中的项目将按标题排序。

//$Color (integer) [0 .. 19]
设置此分类中物件所使用的颜色。
使用与"//$Color"物件定义中相同的值。

//$Arrow (integer) [0 .. 1]
设为 1 时，物件的朝向将在经典模式与视觉模式中显示为箭头。

//$Sprite (string)
设置渲染此物件或此分类中的物件时所使用的精灵图形。这应是带完整名称的精灵名（不含文件扩展名），例如 "CPOSA2"。
你也可以使用「Sprites」目录中的图像：在图像名（不含扩展名）前加上 "internal:" 前缀，例如 "internal:Actor"。

//$Error (integer) [0 .. 2]
设置用于此物件的卡住物件错误检查模式。
可能的值为：

  • 0 - 不检查此物件。
  • 1 - 检查物件是否位于地图几何体之外。
  • 2 - 检查物件是否位于地图几何体之外，或是否卡在另一个物件内部。
默认值为 1。

//$FixedSize (boolean)
设为 true 时，物件将在经典模式与视觉模式中渲染为无尺寸。

//$FixedRotation (boolean)
设为 true 时，在使用编辑选择模式旋转物件时，物件的朝向不会被改变。

//$AbsoluteZ (boolean)
设为 true 时，在视觉模式中物件的垂直位置将被用作绝对值，而不是相对于地板/天花板的距离。

示例：
#region Imp Balls
//$Color 4
//$Sprite "BALLS0"

  actor SuperGiantImpBall : DoomImpBall
  {
    //$Title "我在「Imp Balls」组里！"
    Scale 8.0
    Damage 30
  }

#endregion
