  • 通用界面：

    • 帮助侧边面板，显示当前模式下可用的大部分动作。
    • 现在可以通过将 wad 文件拖拽到 GZDB 主窗口上来加载地图。
    • 打开地图选项、地图选项和游戏配置窗体：可以通过将资源拖拽到资源列表上来添加资源。
    • 游戏配置窗体：可以禁用游戏配置。此设置主要是外观性的。当某个游戏配置被禁用后，它不会出现在新建\打开地图选项和地图选项窗口的"游戏配置"下拉列表中。如果地图的 .dbs 文件指定了已禁用的配置，它仍会被作为地图配置选中。
    • 游戏配置窗体：可以复制和粘贴游戏配置（游戏配置列表现已提供右键菜单）。
    • 数字文本框：除了用 '++NN' 和 '--NN' 按给定值增加或减少外，还可以用 '*NN' 和 '/NN' 按给定值乘或除，用 '+++N' 和 '---N' 按给定值逐次增加或减少。
    • 可以使用右键菜单切换工具栏按钮组。按住 "Shift" 可一次切换多个按钮组。
    • 可以使用工具 -> 保存截图（默认键为 F12）和工具 -> 保存截图（编辑区域）（默认键为 Ctrl-F12）菜单命令保存截图。
    • 可以使用帮助 -> 导出快捷键参考菜单命令将快捷键参考保存为 html 文件。
    • 新动作："在当前 WAD 中打开地图"，可通过文件 -> 在当前 WAD 中打开地图以及 Ctrl-Shift-O 快捷键使用。
    • 新动作："导出为 Wavefront .obj"，可通过文件 -> 导出 -> 选择内容导出为 Wavefront .obj使用。它会将选中的扇区（若未选中扇区，则为整张地图）导出为 Wavefront .obj 模型。
    • 新动作："重新加载 MODELDEF/VOXELDEF"（工具 -> 重新加载 MODELDEF/VOXELDEF）。
    • 新动作："重新加载 GLDEFS"（工具 -> 重新加载 GLDEFS）。
    • 当前选择的信息显示在程序窗口底部。
    • 贴图预览中现在会显示贴图尺寸。您可以取消勾选"首选项 -> 界面 -> 在浏览器中显示贴图和平面贴图尺寸"复选框来禁用此功能。
    • 每个游戏配置可以使用多个游戏引擎。
    • 2D 模式下顶点手柄的大小可以在首选项中更改。
    • 脚本编辑器：按 "F1" 会打开关键字帮助，而不是程序手册。
    • 侧边面板的自动隐藏现在可以更方便地切换。
    • 可以在物件编辑窗体中过滤物件。
    • 新增"提示"侧边面板，显示当前编辑模式下可用的动作列表。
    • 动作和效果可以被过滤（当您记得动作/效果名称，但不记得其编号或类别时很有用）。
    • 可以在首选项窗体中过滤动作。
    • 在主窗口（右下角）新增了错误和警告指示器。点击它可以打开错误和警告窗口。

  • 脚本：

    • 增强的脚本工作流程。
    • 代码片段。
    • 新增对多个 ACC 编译器的支持。
    • BCC 脚本编译器（https://github.com/wormt/bcc/）已随 GZDB 一并捆绑。
    • 在创建或打开地图时可以选择脚本类型，并且可以在地图选项窗体中更改。

    • [已更改] "切换高亮" 动作可在经典模式中使用。
    • [已更改] "亮度增加 8"和"亮度减少 8"动作可在扇区模式中使用。
    • 增强的标签支持。
    • 事件线。
    • 可以在视觉模式下从摄像机位置、在经典模式下从光标位置测试地图。更多信息。
    • 选择可以在经典模式和视觉模式之间同步。更多信息。
    • 摄像机位置可以在经典模式和视觉模式之间同步。更多信息。
    • 您可以使用取色器插件 在经典模式和视觉模式下编辑动态光源属性以及扇区的雾和色调颜色。
    • 您可以使用标签浏览器插件查看当前地图中使用的所有标签和动作。
    • 您可以使用"特殊粘贴属性"动作只粘贴特定属性（可通过快捷键、作为"编辑 -> 特殊粘贴属性..."菜单项以及编辑模式工具栏上的按钮使用）。
    • 您可以对任何地图元素应用随机化变换。
    • 图像浏览器显示文件夹、PK3 和 PK7 资源的目录结构，并可以按贴图类型和尺寸过滤图像。更多信息。
    • 编辑扇区/线段/物件窗体的大多数控件现在可实时工作（例如，当您更改相应数值时，可以立即看到贴图偏移/缩放/旋转的变化）。动作和标签的更改仍然只在您按下"确定"按钮后应用。
    • [UDMF] 所有 UDMF 属性都可以通过编辑扇区/线段/物件/顶点窗口的用户界面进行编辑。
    • 物件编辑窗体有"随机角度"复选框。
    • [UDMF] 如果地图是 UDMF 格式，扇区、线段和顶点信息面板会显示附加信息。

    • 所有绘制模式都可以在模式菜单中使用
    • 物件精灵会在经典模式中渲染。
    • 您可以为线段标志、动作和/或激活方式的任意组合分配自定义颜色。更多信息。
    • 增强的矩形选择。
    • 新动作："转到坐标"，可在视图菜单中使用，也可以通过点击界面右下角的光标坐标使用。
    • 您可以使用涂抹选择 动作更方便地选择地图元素。
    • 绘制矩形模式。
    • 绘制椭圆模式。
    • 绘制曲线模式。
    • 绘制网格模式。
    • 地形导入器模式。
    • 桥梁模式。
    • 吸附地图元素模式。
    • 现在拖动顶点、线段和扇区时，选中的物件也会被拖动。
    • 拖动地图元素时按住 Alt 键，可以将它们相对于初始位置吸附到网格增量。
    • 您可以使用"放置物件"动作，在顶点模式和线段模式下将物件放置在选中的顶点上，在扇区模式下将物件放置在选中的扇区内部。
    • 您可以使用物件统计窗体（编辑 -> 查看物件类型...）查看所有已加载的物件类型和一些附加信息。
    • 您可以使用"绘制设置"面板覆盖用于创建新几何体的默认扇区属性（默认情况下，当新扇区与现有扇区重叠或接触时，编辑器在绘制新扇区时会使用该扇区的贴图、亮度和地板/天花板高度）。
    • 您可以使用工具栏中的此按钮禁用 Doom Builder 的自动清除贴图行为：
    • 您可以更改默认扇区亮度和地板/天花板高度（首选项 -> 编辑 -> 默认扇区设置）。当新扇区不接触或重叠现有扇区时，将使用这些设置。
    • 3D 地板指示（颜色可在首选项 -> 外观 -> 3D 地板中更改，该设置可在首选项中禁用）。
    • 在绘制几何体模式中绘制线段或在任何经典模式中拖动线段时，会显示线段的角度、长度和正面方向。
    • [UDMF] 可以使用工具栏中的此按钮固定地板/天花板贴图偏移：。固定后，贴图将在扇区被拖动时与该扇区对齐。
    • 标签范围插件：现在可以设置自定义增量。
    • 标签范围插件：可以以相对模式设置标签（启用此模式时，生成的值会加到现有标签上，而不是替换它们）。
    • 您可以清除选择组（默认快捷键为 Ctrl-Shift-1 ... 0）。
    • 您可以使用编辑菜单将选择添加到组、选择组和清除组。
    • 地图中心在经典模式中使用高亮颜色显示。

  • 扇区模式：

    • 通过启用扇区 -> 同步物件编辑菜单项 / 同步物件编辑工具栏按钮，物件的选择、拖动和删除可以与扇区的选择、拖动和删除同步。
    • 在（取消）选择扇区时按住 Alt 键，可以（取消）选择物件。启用同步物件编辑选项时，Alt 键的行为会反转。
    • 扇区标签和效果现在可以显示在扇区上方。您可以使用"查看标签和效果"按钮来切换此叠加显示。
    • [UDMF] 创建亮度渐变选项可以在 5 种模式下工作：
    • 扇区信息面板显示扇区的侧面数量以及光照和淡出颜色（仅 UDMF）：
    • "翻转线段"动作现在可以从扇区模式使用。它将尝试对齐线段，使其正面（或背面）指向同一个扇区。

  • 线段模式：

    • [UDMF] 新动作："将天花板贴图对齐到背面"、"将天花板贴图对齐到正面"、"将地板贴图对齐到背面"和"将地板贴图对齐到正面"（可在线段 -> 对齐贴图菜单中使用）。
    • [UDMF] "制作亮度渐变"命令可在线段模式中使用。
    • [UDMF] 线段信息面板：相对 UDMF 光照值显示如下：16（128），表示"UDMF 光照值"（"表面总亮度"）。表面总亮度为 UDMF 光照值 + 扇区亮度。
    • 此模式下会显示分割线段预览（一个矩形，使用信息线颜色着色）。
    • "翻转线段"动作将尝试对齐线段，使其正面（或背面）指向同一个扇区。

  • GZDB 视觉模式：

    • GZDB 视觉模式是 Doom Builder 的视觉模式与 GZDoom 视觉模式合并的成果。

      此模式下可用的新渲染功能：
      • 动态光源（所有类型）在视觉模式中渲染。您可以使用渲染面板切换动态光源的渲染和动画。
      • 在 GLDEFS 中定义的动态光源在视觉模式中渲染（目前每个 actor 仅支持一个 GLDEFS 光源）。
      • 视觉模式中的雾渲染（包括 UDMF 格式地图中的彩色雾）。
      • 新动作："渲染选中/所有模型"。
      • 新动作："切换动态光源动画"。
      • 新动作："切换动态光源渲染"。
      • 新动作："切换雾渲染"。
      • 新动作："切换模型渲染"。
      • 新动作："切换 GZDoom 效果"。
      • 用于 PatrolPoints、摄像机和 InterpolationPoints 的事件线。
      • 半透明 3D 地板可以正确渲染。
      • 高度和半径为 0 的物件也会被渲染。
      • 支持平面复制效果（118）。
      • 支持若干新的 3D 地板标志：
        • "16：使用侧面的上部贴图来绘制侧面"。
        • "32：使用侧面的下部贴图来绘制侧面"。
        • "64：使用加法半透明渲染 3D 地板"。
        • "忽略底部高度"。
      • 当物件类别有精灵而物件本身没有时，使用类别精灵。
      • 墙面上的 Doom 风格明暗（从西到东的墙面比从北到南的墙面稍暗）。此效果受 "vertwallshade"、"horizwallshade"、"evenlighting" 和 "smoothlighting" MAPINFO 属性影响。

    • 此模式下可用的新编辑功能：
      • 您可以Shift-选择（通常选择动作 = 鼠标左键）来选择所有具有相同贴图的相邻表面，Ctrl-选择来选择所有具有相同高度的相邻表面。Ctrl-Shift-选择也会按预期工作。
      • [UDMF] 顶点高度偏移（"zfloor" 和 "zceiling"）可以编辑。
      • [UDMF] 在墙面和天花板上使用"增加/减少亮度"动作（默认绑定到 Ctrl+鼠标滚轮）会更改侧面/天花板亮度，在地板上使用会更改扇区亮度，在 3D 地板上使用会更改 3D 地板的亮度。
      • 您可以使用"切换几何体效果"动作（默认键为 Tab）来切换 GZDoom 的几何体效果，例如斜面、3D 地板、传递亮度效果等。
      • 拖动贴图时按住 Shift 可以将移动锁定到水平轴，按住 Ctrl 可以将其锁定到垂直轴。
      • 拖动贴图时按住 Ctrl-Shift 可以将贴图偏移吸附到当前网格尺寸。
      • 新动作："对齐贴图 X 和 Y"（默认键为 Ctrl-A）。
      • "自动对齐贴图 Y"动作会考虑表面的固定类型。它还会将第一个（高亮的）表面的垂直缩放应用到其余对齐的表面（仅 UDMF）。
      • [UDMF] 自动对齐贴图动作现在会影响 3D 地板的侧面。
      • [UDMF] "自动对齐贴图"动作现在可用于地板和天花板。
      • [UDMF] 新动作："匹配亮度"：此动作使选中表面的亮度与高亮表面的亮度相同。
      • 新动作："将地板/天花板降低到相邻扇区"和"将地板/天花板升高到相邻扇区"（默认键为 PageDown 和 PageUp）。默认情况下，它们会在与选中扇区相邻的扇区中找到下一个更低/更高的表面，并将选中的扇区降低/升高到此高度。如果按住 Ctrl，它们会将扇区降低/升高到选择范围内最低/最高的扇区高度。它们还会将选中的物件下落到地面或对齐到天花板。
      • [UDMF] 新动作："增加缩放"（Num9）、"减少缩放"（Num7）、"增加水平缩放"（Num6）、"减少水平缩放"（Num4）、"增加垂直缩放"（Num8）、"减少垂直缩放"（Num5）动作。这些动作可用于更改物件缩放以及侧面/地板/天花板贴图缩放。
      • [UDMF] 新动作："适应贴图"（默认键为 Ctrl-Alt-A）、"适应贴图宽度"（Alt-A）和"适应贴图高度"（Alt-Shift-A）。
      • 新动作："切换斜面"（默认键为 Alt-S）。选择或高亮上部/下部墙面然后调用此动作可添加斜面。选择或高亮地板或天花板然后调用此动作可移除斜面。
      • 新动作："透过选择查看"（默认键为 "Y"）。此动作将视觉摄像机放置在选中/高亮物件的相同位置，并旋转它以匹配物件的角度。如果目标物件是 AimingCamera、MovingCamera、SecurityCamera 或 InterpolationPoint，则有特殊处理。
      • 新动作："自动将贴图对齐到选择 (X)"、"自动将贴图对齐到选择 (Y)"和"自动将贴图对齐到选择 (X 和 Y)"。
      • 新动作："顺时针旋转"和"逆时针旋转"，可用于旋转物件以及 [UDMF] 地板/天花板贴图。
      • 新动作："顺时针更改俯仰"、"逆时针更改俯仰"、"顺时针更改翻滚"和"逆时针更改翻滚"，可用于更改选中或高亮物件的俯仰和翻滚。
      • 可以使用"向前/向后/向左/向右移动物件"动作水平移动物件。
      • 可以使用"将物件移动到光标位置"（默认键为 Ctrl + 鼠标中键）动作将物件移动到光标位置。
      • 可以使用"插入项目"动作（默认键为 Insert）在光标位置插入物件。
      • 可以使用"删除项目"动作（默认键为 Delete）删除选中的物件。
      • 选中的物件可以在光标位置剪切/复制/粘贴。
      • [UDMF] 现在使用方向键移动贴图偏移时会考虑地板/天花板贴图旋转。
      • [UDMF] 新动作："重置局部贴图偏移 (UDMF)"。它会重置目标或选中侧面的上部/中部/下部贴图偏移、缩放和亮度，重置目标或选中地板/天花板的贴图偏移、旋转、缩放和亮度，并重置目标或选中物件的缩放、俯仰和翻滚。
      • [UDMF] "重置贴图偏移"动作现在会重置目标或选中地板和天花板的贴图偏移，并且还会重置目标或选中物件的缩放。

  • 自定义字段：

    • 整数（随机）自定义字段类型。
    • 小数（随机）自定义字段类型。

  • 地图分析模式：

    • 可以通过结果列表的右键菜单按结果类型以及单独隐藏分析结果。
    • 地图分析模式可以检查地图中的未连接顶点。
    • 地图分析模式可以检查地图中的重叠线段。这将检查两条线段是否具有相同的起点和终点位置。
    • 地图分析模式可以检查地图中的重叠顶点。这将检查某个顶点是否位于某条线段或另一个顶点之上。
    • 地图分析模式可以检查地图中的无效扇区（侧面少于 3 个的扇区或没有面积的扇区）。
    • 地图分析模式可以检查地图中未使用的贴图。
    • 地图分析模式可以检查地图中缺失的平面贴图。
    • 地图分析模式可以检查地图中的未知物件（其类型未在 DECORATE 或当前游戏配置中定义的物件）。
    • 地图分析窗口现在有"应用于此类型的所有错误"复选框。
    • 分析结果可以保存到文本文件或复制到剪贴板。

  • 查找与替换模式：

    • 查找与替换模式现在有"扇区亮度"、"扇区地板高度"、"扇区天花板高度"、"线段标志"、"物件标志"、"侧面标志"和"扇区标志"搜索模式。
    • "任何贴图或平面贴图"、"扇区平面贴图"和"侧面贴图"搜索模式现在支持 "*"（匹配任意数量的字符）和 "?"（匹配任意单个字符）通配符。
    • 查找与替换模式可以查找和替换带有特定参数的物件和线段动作。语法为"[Action] [arg1] [...]"。ACS 动作使用的脚本名称也可以通过这种方式替换（仅 UDMF）。

  • 杂项功能：

    • 节点查看器插件支持 "XNOD"、"XGLN"、"XGL2" 和 "XGL3" 格式的 ZNODES。
    • 选择组会保存到地图的 .dbs 文件中。

  • (G)ZDoom 功能支持：

    • 在 2D 和 3D 模式中渲染MD2 和 MD3 模型。
    • VOXLEDEF 支持。
    • REVERBS 支持（用于声音环境模式）。
    • 更完整的 TEXTURES 支持。
    • 部分 MAPINFO 支持，包括 DoomEdNum 和 SpawnNums 覆盖。
    • 带 #include 指令的 ACS 脚本可以正确编译。
    • 支持 PNG 和 PCX 图像格式。
    • 支持 PK7 归档格式。
