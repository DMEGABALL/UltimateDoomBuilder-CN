关于脚本配置

脚本配置用于在脚本编辑器中提供代码高亮（Highlight）和代码补全。
脚本配置从放置在 "Scripting" 目录中的 *.cfg 文件加载。

脚本编译器设置：


compiler (string)
要使用的脚本编译器的名称。

parameters (string)
传递给脚本编译器的命令行参数。 支持以下通配符：
  • "%FI" - 输入文件路径。
  • "%FO" - 输出文件路径。
  • "%FS" - 源文件。
  • "%PT" - 临时目录路径。
  • "%PS" - 源路径。
resultlump (string)
编译结果应存放到的 lump 名称。


脚本编辑器设置：


description (string)
显示在脚本编辑器"New File" 下拉菜单中的脚本类型名称。

codepage (integer)
Scintilla 控件将使用的代码页。

extensions (string)
与此配置关联的文件扩展名列表，以逗号分隔。

casesensitive (boolean)
该脚本类型是否区分大小写？默认值为 true。

insertcase (int)
0 - 常规，1 - 小写，2 - 大写。默认值为 0。

lexer (integer)
指定 Scintilla 控件将使用的词法分析器类型。
可能的值有：1 - 纯文本；3 - CPP 风格，区分大小写；6 - Perl 风格；18 - Pascal 风格；35 - CPP 风格，不区分大小写。

functionopen (string)
用作函数起始花括号的字符。

functionclose (string)
用作函数结束花括号的字符。

argumentdelimiter (string)
用作函数参数分隔符的字符。

terminator (string)
用作表达式终止符的字符。

keywordhelp (string) - 仅限 GZDB。
用于显示关键字帮助的 URL。"%K" 占位符将被替换为调用关键字帮助（F1）时文本光标所在位置的单词文本。

snippetsdir (string) - 仅限 GZDB。
"Snippets" 目录内的目录名称，其中存放当前脚本配置的代码片段。

scripttype (string) - 仅限 GZDB。
将当前脚本配置标记为 GZDB 能够识别的脚本类型之一。可能的值有 "UNKNOWN"（默认）、"ACS"、"MODELDEF"、"DECORATE"、"GLDEFS"、"SNDSEQ"、"MAPINFO"、"VOXELDEF"、"TEXTURES"、"ANIMDEFS"、"REVERBS"、"TERRAIN"、"X11R6RGB"、"CVARINFO"、"SNDINFO"、"LOCKDEFS"、"MENUDEF"、"SBARINFO" 和 "USDF"。

"keywords" 块：


定义要高亮并为其显示代码补全的关键字列表。 每个关键字的定义形式为 
Keyword = "Keyword description";
"Keyword" 是脚本中使用的单词，"Keyword description" 提供有关关键字的附加信息，例如函数参数，或关于该函数及其参数作用的提示。

示例： 

keywords
{
	CanRaiseActor = "bool CanRaiseActor(int tid)\nChecks to see if the actor or actors with the specified tid are viable for resurrection.\nIf tid is 0, the check is done on the activator of the script.";
}

"constants" 块：


定义要高亮并为其显示代码补全的常量列表。

示例： 

constants
{
	AAPTR_DEFAULT;
	AAPTR_FRIENDPLAYER;
	AAPTR_GET_LINETARGET;
	AAPTR_MASTER;
	AAPTR_NULL;
}
