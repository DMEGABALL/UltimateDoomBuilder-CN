常见问题

问：我收到了大量“Unable to find the DECORATE class '[some actor]' to inherit from, while parsing '[some other actor]:[DoomEdNum]”警告。出了什么问题？
答：当某个 DECORATE 角色继承自另一个角色，而后者既未在游戏配置中定义，也未在任何已包含的资源中定义时，就会发生这种情况。
如果你使用的是 (G)ZDoom：
要解决此问题，请将“(g)zdoom.pk3”添加为地图资源。添加时不要忘记勾选“Exclude from testing parameters”复选框，否则 (G)ZDoom 将无法加载你的地图。“(g)zdoom.pk3”可以在 (G)ZDoom 文件夹中找到。
如果你使用的是 Zandronum：
要解决此问题，请将“zandronum.pk3”添加为地图资源。如果你要使用 Skulltag 怪物，还需要添加“skulltag_actors.pk3”和“skulltag_data.pk3”。添加其中任何一个时都不要忘记勾选“Exclude from testing parameters”复选框，否则 Zandronum 将无法加载你的地图。“zandronum.pk3”和“skulltag_actors.pk3”可以在 Zandronum 文件夹中找到。你需要自行寻找“skulltag_data.pk3”。


问：在 GLDEFS 中定义的动态光源（Dynamic Light）在视觉模式（Visual Mode）中未渲染 / 我收到了大量“Light declaration not found for light '[light name]' ('[source]', line [n])”警告。出了什么问题？
答：GZDoom Builder 不包含 GZDoom/Zandronum 的 GLDEFS 光源定义。
如果你使用的是 GZDoom：
要消除这些错误，请将“lights.pk3”添加为地图资源。“lights.pk3”可以在 GZDoom 文件夹中找到。
如果你使用的是 Zandronum：
要消除这些错误，请将“zandronum.pk3”添加为地图资源。添加时不要忘记勾选“Exclude from testing parameters”复选框，否则 Zandronum 将无法加载你的地图。“zandronum.pk3”可以在 Zandronum 文件夹中找到。


问：我不喜欢 GZDB 在视觉模式中渲染扇区墙壁时使用的“假对比度”（zdoom.org/wiki/Fake_contrast）。如何禁用它？
答：GZDB 的视觉模式会模拟 (G)ZDoom 的默认渲染偏好（在 (G)ZDoom 中，“选项 -> 显示选项 -> 使用假对比度”默认处于“开启”状态）。你可以通过在 MAPINFO 的“map”或“defaultmap”定义中添加“evenlighting”或“smoothlighting”属性来改变这种行为。关于 GZDB 支持的 MAPINFO 属性的更多信息可以在此处找到。
