系统要求

系统要求：

  • 2.4 GHz 或更快的 CPU。（建议使用多核）。
  • Windows XP、Vista、7、8 或 10。
  • 支持 Pixel Shader model 2.0 的显卡。
所需软件：
  • Microsoft Visual C++ 2008 SP1 Redistributable Package (x86)（仅 Nodes Viewer 插件需要）。
  • Microsoft .Net Framework 3.5。注意：如果你已经安装了 .Net Framework 4.0 或更高版本，你仍然需要安装 3.5 版本，因为较新的版本并不向后兼容它！
  • DirectX 9.0 Runtime。注意：即使你已安装 DirectX 11，也仍然需要它。
注意：使用 GZDoom Builder 安装程序时，这些组件会被自动安装。
