曲线线段模式

此模式会显示一个小对话框，你可以用它从一条线段或多条线段创建曲线。这些线段将被分割成若干较短的线段，共同构成曲线。虽然此模式会显示对话框，你仍可使用主界面，并在地图上缩放或移动视图。

曲线线段编辑模式是经典（2D）编辑模式之一。此模式是易变的，这意味着当地图保存或关闭时，此模式会返回上一个稳定模式，并接受或放弃你的预览更改。你可以通过线段模式进入此模式。

默认控制

Enter 接受并应用更改，然后返回上一个模式。
Escape 放弃更改并返回上一个模式。
Ctrl + Mousewheel 增加/减少分割顶点数。
LMB + Drag 更改曲线的距离（未设置固定圆弧曲线时）。
RMB + Drag 更改曲线的角度。
Ctrl + Alt + RMB + Drag 设置固定圆弧曲线后，在更改曲线角度的同时增加/减少分割顶点数，以保持一致圆弧曲线
