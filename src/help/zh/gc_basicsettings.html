游戏配置 - 基础设置

type (string)
这表示配置的类型，用于防止误用其他配置。必须始终为字符串 "Doom Builder 2 Game Configuration"。

game (string)
在 Doom Builder 中为您的游戏配置显示的名称。
默认值为 "<unnamed game>"。

enabledbydefault (boolean) - 仅 GZDB。
此游戏配置默认可用。您可以使用游戏配置窗口启用和禁用游戏配置。
默认值为 false。

actionspecialhelp (string) - 仅 GZDB。
用于显示动作特殊帮助的 URL。"%K" 通配符将被动作定义中定义的 id 属性替换。

thingclasshelp (string) - 仅 GZDB。
在「物件编辑」窗体中点击物件类名时要打开的 URL。"%K" 通配符将被物件定义中定义的 classname 属性或 DECORATE actor 名称替换。

basegame (string) - 仅 GZDB。
表示当前配置基于哪个游戏。用于加载特定于游戏的 GLDEFS lump（DOOMDEFS、HTICDEFS、HEXNDEFS 或 STRFDEFS）。
可能的值："Doom"、"Heretic"、"Hexen"、"Strife" 或 "Chex"。
如果未设置，则不会加载特定于游戏的 lump。

engine (string)
游戏引擎/源代码移植版名称。它被用作 UDMF 地图格式接口的 UDMF 命名空间。目前没有其他作用。

defaultlumpname (string)
创建新地图并选择此配置时建议使用的默认 lump 名称。

testparameters (string)
用于启动测试游戏引擎的默认参数。可用参数占位符请参阅游戏配置窗口。

testshortpaths (boolean)
设置为 true 可默认使用 MSDOS 8.3 格式的路径和文件名。用户仍可在游戏配置窗口中更改此设置。
默认值为 false。

defaultsavecompiler (string)
用作保存地图时所使用编译器默认设置的节点构建器编译器配置结构的名称。用户仍可在游戏配置窗口中更改此设置。

defaulttestcompiler (string)
用作测试地图时所使用编译器默认设置的节点构建器编译器配置结构的名称。用户仍可在游戏配置窗口中更改此设置。

defaultscriptcompiler (string) - 仅 GZDB。
用作编译地图脚本时所使用脚本编译器默认设置的脚本编译器配置文件的名称。用户仍可在地图选项窗口中更改此设置。

skills (structure)
这定义了用户在使用此游戏引擎/项目时可用的难度选项。此结构中的设置应为数字，值为字符串（难度等级的描述性名称）。

示例： 

skills
{
	1 = "I'm too young to die";
	2 = "Hey, not too rough";
	3 = "Hurt me plenty";
	4 = "Ultra-Violence";
	5 = "Nightmare!";
}

damagetypes (string) - 仅 GZDB。
内置伤害类型的空格分隔列表。此列表会与从 DECORATE 解析出的 DamageTypes 合并。

示例： 
damagetypes = "None BFGSplash Drowning Slime";

internalsoundnames (string) - 仅 GZDB。
内置逻辑声音名称的空格分隔列表。当这些名称未在 SNDINFO 中绑定到实际声音时，不会触发编辑器警告。

示例： 
internalsoundnames = "*death *xdeath *wimpydeath *crazydeath *burndeath";

ignoredextensions (string) - 仅 GZDB。
文件扩展名的空格分隔列表。加载 PK3/PK7/目录资源时，将忽略具有这些扩展名的文件。

示例： 
ignoredextensions = "wad pk3 pk7 bak backup1 backup2 backup3 zip rar 7z";

ignoreddirectories (string) - 仅 GZDB。
目录名称的空格分隔列表。加载 PK3/PK7/目录资源时，将忽略这些目录名称。这仅适用于顶层目录。

示例： 
ignoreddirectories = ".svn .git";

linetagindicatesectors (boolean)
当为 true 时，Doom Builder 会在高亮某条线段时高亮具有相同标签编号的扇区。这只对 Doom 格式的地图真正有用，因为 Hexen 格式和 UDMF 格式的线段上没有单一的标签（在这些格式中，线段动作的参数可以是标签，这同样可以用于高亮扇区）。
默认值为 false。

singlesidedflag (integer or string)
此设置让 Doom Builder 知道表示只有一侧的线段的线段标志。当 Doom Builder 将一条线改为单面时，会在线段上设置此标志值；当线变为双面时，会从线段上移除此标志。插件也可以使用此信息对线段执行操作。对于使用数字标志的地图格式（Doom 和 Hexen），这必须是整数标志值。对于使用命名标志的地图格式（UDMF），这必须是指示标志名称的字符串。

doublesidedflag (integer or string)
此设置让 Doom Builder 知道表示有两个侧面的线段的线段标志。当 Doom Builder 将一条线改为双面时，会在线段上设置此标志值；当线变为单面时，会从线段上移除此标志。插件也可以使用此信息对线段执行操作。对于使用数字标志的地图格式（Doom 和 Hexen），这必须是整数标志值。对于使用命名标志的地图格式（UDMF），这必须是指示标志名称的字符串。

impassableflag (integer or string)
此设置让 Doom Builder 知道表示阻挡玩家和怪物的线段的线段标志。Doom Builder 使用此信息为线段指定特殊颜色，插件可以使用此信息执行与阻挡声音线相关的操作。对于使用数字标志的地图格式（Doom 和 Hexen），这必须是指定「不可通行」标志值的整数。对于使用命名标志的地图格式（UDMF），这必须是指示「不可通行」标志名称的字符串。

leftboundary (integer)
地图左边界。
默认值为 -32768。

rightboundary (integer)
地图右边界。
默认值为 32767。

topboundary (integer)
地图上边界。
默认值为 32767。

bottomboundary (integer)
地图下边界。
默认值为 -32768。

safeboundary (integer) - 仅 GZDB。
被「检查地图尺寸」错误检查视为安全的最大地图包围盒尺寸。将此值设为 0 可禁用该检查。
默认值为 32767。

defaultwalltexture (string) - 仅 GZDB。
创建新扇区时用于侧面的贴图名称。
默认值为 "STARTAN"。

defaultfloortexture (string) - 仅 GZDB。
创建新扇区时用于地板的平面贴图名称。
默认值为 "FLOOR0_1"。

defaultceilingtexture (string) - 仅 GZDB。
创建新扇区时用于天花板的平面贴图名称。
默认值为 "CEIL1_1"。

makedoortrack (string)
制作门时用于墙壁的贴图名称。
默认值为 "-"（无贴图）。

makedoordoor (string) - 仅 GZDB。
制作门时用作门贴图的贴图名称。
默认值为 "-"（无贴图）。

makedoorceil (string) - 仅 GZDB。
制作门时用作门天花板贴图的贴图名称。
默认值为 "-"（无贴图）。

makedooraction (integer)
制作门时要放在线条上的线段动作编号。

makedoorarg# (0 .. 4) (integer)
制作门时要放在线条上的线段动作编号的参数。

doomlightlevels (boolean)
将此设置为 false 可在 Doom Builder 中使用线性光照。通常 Doom Builder 使用对 Doom 光照等级的模拟。
默认值为 true。

doomthingrotationangles (boolean) - 仅 GZDB。
当设置为 true 时，与更改物件角度相关的编辑器动作会将结果角度吸附到 45 度的增量。
默认值为 false。

localsidedeftextureoffsets (boolean) - 仅 GZDB。
当设置为 true 时，启用编辑器内对侧面（Sidedef）上/中/下贴图独立偏移的支持。仅影响 UDMF 地图格式。
默认值为 false。

start3dmode (integer)
Doom Builder 用于在地图中保存视觉模式相机位置的物件类型编号。Doom Builder 会在地图中放置一个该类型的物件，并在您在视觉模式中移动时随之移动它。

skyflatname (string)
被解释为天空（表示没有天花板）的平面贴图名称。Doom Builder 和插件可以将此信息用于各种用途。
默认值为 "F_SKY1"。

defaultskytextures (structure) - 仅 GZDB。
定义原版地图使用的地图名称与天空贴图名称之间的关系。

示例： 
defaultskytextures
{
	SKY1 = "MAP01,MAP02,MAP03,MAP04,MAP05";
	SKY2 = "MAP12,MAP13,MAP14,MAP15,MAP16";
	SKY3 = "MAP21,MAP22,MAP23,MAP24,MAP25";
}

longtexturenames (boolean) - 仅 GZDB。
启用对长（> 8 个字符）贴图名称的支持。GZDoom Builder 使用此设置来限制用户界面中的输入字段，并检查资源中贴图名称的有效性。此设置应仅对 UDMF 游戏配置启用。启用此设置会使地图与 Doom Builder 2 不兼容，并可能在 Slade 3 中导致问题。这并不能决定地图文件格式中对贴图名称的实际限制。
默认值为 false。

sidedefcompressionignoresaction (boolean) - 仅 GZDB。
当设置为 true 时，无论线段动作或标签为何，都会压缩侧面（DB2 行为，当目标源代码移植版不反压缩侧面时可能引发问题）。
当设置为 false 时，属于带有动作或非零标签的线条的侧面在压缩侧面时将被跳过。
默认值为 false。

filetitlestyle (string)
定义加载的目录或 PK3/PK7/PKE 资源中的长文件名如何转换为 lump 名称。
可能的值有：
  • "default" - 移除扩展名，然后保留其余名称
  • "zdoom" - 移除扩展名，然后保留其余名称的前 8 个字符
  • "eternityengine" - 移除第一个点之后的所有内容（包括该点），然后保留其余名称的前 8 个字符
默认值为 "default"。
