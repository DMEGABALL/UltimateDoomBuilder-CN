游戏配置 - 动作参数设置

title (string)
设置此参数的标题。
参数标题也可以在 DECORATE 中设置。

tooltip (string) - 仅 GZDB
允许为物件或线段参数定义指定显示的提示文本。可以使用换行符（"\n"）来格式化文本。
参数提示也可以在 DECORATE 中设置。
示例： 

arg1
{
    title = "Mirror Polyobj Number";
    tooltip = "Polyobject that will mirror\nthis one's movements.";
}

type (integer)
设置此参数的类型。这会改变 线段与 物件编辑窗口中参数输入框的行为。
参数类型也可以在 DECORATE 中设置。
支持的值有：

  • 0 = 整数（默认）
  • 4 = 动作特殊
  • 5 = 扇区效果
  • 8 = 角度（度）
  • 10 = XXRRGGBB 颜色
  • 11 = 枚举选项
  • 12 = 枚举位
  • 13 = 扇区标签
  • 14 = 物件标签
  • 15 = 线段标签
  • 22 = 字节角度（仅 GZDB）
  • 23 = 物件半径（仅 GZDB）
  • 24 = 物件高度（仅 GZDB）
  • 25 = 多段体编号（仅 GZDB）
  • 26 = 枚举选项 + 枚举位（仅 GZDB）

targetclasses (string) - 仅 GZDB
设置后，参数下拉列表中将只显示属于给定类的物件。仅在参数 type 为 14 时使用。
该值可以是单个物件类名，或以逗号分隔的物件类名列表：

arg0
{
    title = "MapSpot Tag";
    type = 14;
    targetclasses = "MapSpot,MapSpotGravity";
}

enum (structure or string)
提供用于显示此参数的预定义值列表。仅在参数 type 为 11 或 12 时使用。
该值可以是预定义枚举的名称：

arg0
{
    title = "Volume";
    type = 11;
    enum = "sound_volume";
}
也可以是显式定义：
arg0
{
    title = "Apply to";
    type = 11;
    enum
    {
        0 = "Floor and Ceiling";
        1 = "Ceiling";
        2 = "Floor";
    } 
}
枚举也可以在 DECORATE 中设置。

renderstyle (string) - 仅 GZDB
允许指定用于显示此参数值的渲染形状。支持的值有：

  • "Rectangle"。参数值用作矩形尺寸。
  • "Circle"。参数值用作圆形半径。
渲染形状可通过"Toggle Event Lines"动作/菜单按钮切换。
目前渲染形状仅支持物件参数。
目前渲染形状仅在经典模式中显示。

rendercolor (integer) - 仅 GZDB
允许指定渲染形状所使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，渲染形状将使用事件线编辑器颜色。
此属性必须与 "renderstyle" 属性配合使用。

minrange (integer) - 仅 GZDB
允许指定渲染形状的最小范围。
默认情况下，最小范围形状将使用指示编辑器颜色。
此属性必须与 "renderstyle" 属性配合使用。

minrangecolor (integer) - 仅 GZDB
允许指定渲染最小范围形状时使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，最小范围形状将使用指示编辑器颜色。
此属性必须与 "renderstyle" 和 "minrange" 属性配合使用。

maxrange (integer) - 仅 GZDB
允许指定渲染形状的最大范围。
默认情况下，最大范围形状将使用指示编辑器颜色。
此属性必须与 "renderstyle" 属性配合使用。

maxrangecolor (integer) - 仅 GZDB
允许指定渲染最大范围形状时使用的颜色。支持的值有十六进制颜色（如 "FF0000"）、HTML 格式的十六进制颜色（如 "#F00" 或 "#FF0000"）或颜色名称（如 "Red"）。
默认情况下，最大范围形状将使用指示编辑器颜色。
此属性必须与 "renderstyle" 和 "maxrange" 属性配合使用。

flags (structure or string) - 仅 GZDB
提供用于显示此参数的预定义位标志值列表。仅在参数 type 为 26 时使用。
该值可以是预定义枚举的名称，也可以是显式定义。
示例： 

	arg4
	{
		title = "Flags";
		type = 26;
		// 一次只能选择一个枚举值
		enum
		{
			0 = "Don't copy anything";
			1 = "Copy floor texture, remove sector special";
			2 = "Copy floor texture";
			3 = "Copy floor texture and special";
		}
		// 可以选择任意数量的标志值
		flags
		{
			4 = "Use numeric model if set, trigger model if not";
			8 = "Raise floor if set, lower it if not";
			16 = "Inflict crushing damage";
		}
	}

default (integer) - 仅 GZDB
设置物件或线段参数定义的默认值。
默认值也可以在 DECORATE 中设置。
示例： 

9038
{
    title = "ColorSetter";
    arg0
    {
        title = "Red";
        default = 255;
    }
}
