游戏配置 - 资源设置

decorategames (string)
在此填入要支持的 DECORATE 角色所属的游戏名称。只有游戏名称包含在该字符串中的 DECORATE 角色才会被加载。如果未设置此项，则不会加载 DECORATE lump。

示例： 

decorategames = "heretic raven";

mixtexturesflats (boolean)
当此项设为 true 时，Doom Builder 将允许在墙上使用平面贴图、在地板上使用贴图。贴图与平面贴图混合时会优先考虑其原本用途。对于贴图来说，这意味着贴图会覆盖同名的平面贴图；对于平面贴图来说，这意味着平面贴图会覆盖同名的贴图。默认值为 false。

defaulttexturescale (decimal)
在缩放比例未知时贴图所用的缩放。这是一个标量值：0.5 表示原始尺寸的一半、分辨率的两倍。默认值为 1.0。

defaultflatscale (decimal)
在缩放比例未知时平面贴图所用的缩放。这是一个标量值：0.5 表示原始尺寸的一半、分辨率的两倍。默认值为 1.0。

scaledtextureoffsets (boolean)
决定贴图偏移使用世界坐标（不受贴图缩放影响）还是贴图坐标。设为 true 以使用贴图坐标。默认值为 false。

textures (structure)
此设置列出标记 lump 的名称，这些标记指示 Doom Builder 应加载的贴图列表的起点和终点。每个范围都必须有单独的结构，结构名称无关紧要。范围必须包含 'start' 设置和 'end' 设置，其值必须是起始与结束 lump 的名称 (string)。请注意，PNAMES、TEXTURE1 和 TEXTURE2 lump 不需要写入游戏配置，只要存在就会始终被加载。

示例： 
textures
{
	zdoom1
	{
		start = "TX_START";
		end = "TX_END";
	}
}

patches (structure)
此设置列出标记 lump 的名称，这些标记指示 Doom Builder 应加载的补丁列表的起点和终点。每个范围都必须有单独的结构，结构名称无关紧要。范围必须包含 'start' 设置和 'end' 设置，其值必须是起始与结束 lump 的名称 (string)。请注意，Doom Builder 不会加载所有补丁，只加载贴图所使用的那些。

示例： 
patches
{
	standard1
	{
		start = "P_START";
		end = "P_END";
	}
	
	standard2
	{
		start = "PP_START";
		end = "PP_END";
	}
}

sprites (structure)
此设置列出标记 lump 的名称，这些标记指示 Doom Builder 应加载的精灵列表的起点和终点。每个范围都必须有单独的结构，结构名称无关紧要。范围必须包含 'start' 设置和 'end' 设置，其值必须是起始与结束 lump 的名称 (string)。请注意，Doom Builder 不会加载所有精灵，只加载物件所使用的那些。

示例： 
sprites
{
	standard1
	{
		start = "S_START";
		end = "S_END";
	}
}

flats (structure)
此设置列出标记 lump 的名称，这些标记指示 Doom Builder 应加载的平面贴图列表的起点和终点。每个范围都必须有单独的结构，结构名称无关紧要。范围必须包含 'start' 设置和 'end' 设置，其值必须是起始与结束 lump 的名称 (string)。

示例： 
flats
{
	standard1
	{
		start = "F_START";
		end = "F_END";
	}
}

此设置列出标记 lump 的名称，这些标记指示 Doom Builder 应加载的颜色映射列表的起点和终点。每个范围都必须有单独的结构，结构名称无关紧要。范围必须包含 'start' 设置和 'end' 设置，其值必须是起始与结束 lump 的名称 (string)。

示例： 
colormaps
{

}
