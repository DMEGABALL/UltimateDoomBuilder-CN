游戏配置 - 地图格式设置

formatinterface (string)
Doom Builder 中用于读取和写入地图数据的接口类名。

  • 对于 Doom 地图格式，使用 "DoomMapSetIO"。这是一种使用数值标志的地图格式。
  • 对于 Hexen 地图格式，使用 "HexenMapSetIO"。这是一种使用数值标志的地图格式。
  • 对于 UDMF 地图格式，使用 "UniversalMapSetIO"。这是一种使用命名标志的地图格式。
maplumpnames (structure)
此结构描述构成完整地图的各个 lump，包括脚本和节点。它还必须指明 Doom Builder 应如何处理这些 lump，以及/或者这些 lump 来自何处。这些 lump 通常由地图格式接口类写入，但有些可能由节点构建编译器生成，或由 Doom Builder 直接存储。在此结构中，每个地图 lump 都应有一个结构。结构的名称应为 lump 名称的大写形式。对于地图头（其名称各不相同），可以使用 ~MAP 这个名称。以下设置应位于 lump 结构中（除非适用默认值）：
  • required (boolean)
    True 表示此 lump 是地图必需的 lump。默认值为 false。

  • forbidden (boolean) - 仅 GZDB。
    True 表示此 lump 不得存在于地图的命名空间中。默认值为 false。

  • blindcopy (boolean)
    当 Doom Builder 应随地图一起复制此 lump 而不使用它时，将其设为 true。默认值为 false。

  • nodebuild (boolean)
    设为 true 时，表示节点构建编译器会生成或修改此 lump。默认值为 false。

  • allowempty (boolean)
    设为 true 以允许节点构建器将此 lump 保留为空。默认值为 false。

  • script (string)
    设置此项时，表示此 lump 可以用脚本编辑器编辑。此 lump 的内容将自动加载到脚本编辑器中。将值设为要使用的脚本配置的 .cfg 文件名（不含路径）。

  • scriptbuild (boolean) - 仅 GZDB。
    设置此项时，表示此 lump 可以用脚本编辑器编辑。将使用当前选定的脚本配置来构建此 lump。此 lump 的内容将自动加载到脚本编辑器中。
示例：
maplumpnames
{
	~MAP
	{
		required = true;
		blindcopy = true;
		nodebuild = false;
	}
	
	THINGS
	{
		required = true;
		nodebuild = true;
		allowempty = true;
	}
	
	LINEDEFS
	{
		required = true;
		nodebuild = true;
		allowempty = false;
	}
	
	SIDEDEFS
	{
		required = true;
		nodebuild = true;
		allowempty = false;
	}
	
	VERTEXES
	{
		required = true;
		nodebuild = true;
		allowempty = false;
	}
	
	SEGS
	{
		required = false;
		nodebuild = true;
		allowempty = false;
	}
	
	SSECTORS
	{
		required = false;
		nodebuild = true;
		allowempty = false;
	}
	
	NODES
	{
		required = false;
		nodebuild = true;
		allowempty = false;
	}
	
	SECTORS
	{
		required = true;
		nodebuild = true;
		allowempty = false;
	}
	
	REJECT
	{
		required = false;
		nodebuild = true;
		allowempty = false;
	}
	
	BLOCKMAP
	{
		required = false;
		nodebuild = true;
		allowempty = false;
	}
	
	SCRIPTS
	{
		required = false;
		nodebuild = false;
		script = "ZDoom_ACS.cfg";
	}
}

universalfields (structure) - 仅 UDMF。
提供额外的 UDMF 字段定义，以便在编辑窗口的 Custom 选项卡中显示。
警告：只添加 Doom Builder 不会通过其自带用户界面编辑的字段！
警告："default" 字段必须与 UDMF 规范一致！

字段数据类型：
  • 0 = 整数
  • 1 = 浮点数
  • 2 = 字符串
  • 3 = 布尔值
  • 4 = 线段类型 (integer)
  • 5 = 扇区效果 (integer)
  • 6 = 贴图 (string)
  • 7 = 平面贴图 (string)
  • 8 = 角度（度，整数）
  • 9 = 角度（弧度，浮点数）
  • 10 = XXRRGGBB 颜色 (integer)
  • 11 = 枚举选项 (integer)
  • 12 = 枚举位 (integer)
  • 13 = 扇区标签 (integer)
  • 14 = 物件标签 (integer)
  • 15 = 线段标签 (integer)
  • 16 = 枚举选项 (string)
  • 17 = 角度（度，浮点数）
  • 22 = 字节角度 (integer) - 仅 GZDB
示例：
universalfields
{
	linedef
	{
		comment
		{
			type = 2;
			default = "";
		}
	}
	
	sidedef
	{
		comment
		{
			type = 2;
			default = "";
		}
	}
	
	thing
	{
		comment
		{
			type = 2;
			default = "";
		}
    
		skill6
		{
			type = 3;
			default = false;
		}

    
		class6
		{
			type = 3;
			default = false;
		}

	}
	
	sector
	{
		comment
		{
			type = 2;
			default = "";
		}
	}
}
