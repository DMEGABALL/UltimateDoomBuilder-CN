(G)ZDoom 文本 lump 支持

如果地图的资源中存在以下 lump，GZDoom Builder 将自动从中加载数据：

DECORATE：

角色定义会被加载，并用于填充物件（Thing）列表。可以使用特殊注释来指定额外参数。
伤害类型会被加载，并用于“编辑扇区”窗口的“伤害类型”下拉列表中（仅限 UDMF）。

TEXTURES：

你可以使用“//$GZDB_SKIP”特殊注释来中止对当前文件的解析。如果你不希望某些文件或文件某些部分的贴图出现在图像浏览器中，或者希望加快资源加载速度，这会很有用。

GZDoom Builder 增加了对以下 TEXTURES 参数的支持：
  • FlipX、FlipY、Rotate 和 Blend（两种样式）patch 参数。
  • “Add”、“Modulate”、“Subtract”、“ReverseSubtract”和“Translucent” patch 半透明样式。

(Z)MAPINFO：

同时支持新版和旧版 MAPINFO 定义样式。
你可以使用“//$GZDB_SKIP”特殊注释来中止对当前文件的解析。
支持 DoomEdNum 覆盖。
支持 SpawnNums 覆盖。这些值用于更新“spawnthing”游戏配置枚举。

此外，视觉模式支持 (Z)MAPINFO 中的以下值：
  • fade；
  • outsidefog；
  • fogdensity；
  • outsidefogdensity；
  • vertwallshade；
  • horizwallshade；
  • evenlighting；
  • smoothlighting。

REVERBS：

声音环境（Sound Environment）定义会被加载，并可在声音环境模式中使用。

SNDINFO：

环境音定义会被加载。这些值用于更新“Ambient Sound NN”物件的标题，并填充“ambient_sounds”游戏配置枚举。

SNDSEQ：

声音序列和声音序列组定义会被加载，并可在“编辑扇区”窗口的“声音序列”下拉列表中选择（仅限 UDMF）。

LOCKDEFS：

锁定义会被加载。这些值用于填充“keys”游戏配置枚举。
你可以在锁的定义体内部添加“//$Title”特殊注释来指定锁的标题。

TERRAIN：

地形名称会被加载，并用于“编辑扇区”窗口的地板和天花板“地形”下拉列表中（仅限 UDMF）。

X11R6RGB：

颜色会被加载，并在适当之处供其他文本解析器使用。

CVARINFO：

CVAR 会被加载。目前编辑器仅将它们用于“DistanceCheck” DECORATE 属性支持。

MODELDEF：

支持所有相关的 MODELDEF 属性和标志，但 sprite translations 除外。

VOXELDEF：

支持所有相关的 VOXELDEF 属性和标志。

GLDEFS：

目前仅支持发光平面贴图和动态光源定义。将来可能会添加 Brightmaps 支持。
你可以使用“//$GZDB_SKIP”特殊注释来中止对当前文件的解析。

你可以使用“Reload GLDEFS”和“Reload MODELDEF”动作重新加载 GLDEFS 和 MODELDEF。
要启用 GZDoom 内置的 GLDEFS 动态光源定义，你需要将“lights.pk3”添加为地图资源。“lights.pk3”可以在 GZDoom 文件夹中找到。

关于 MODELDEF 和 GLDEFS 支持的附加信息：

如果你正在为 Doom 或 Doom 2 制作地图，可能不需要阅读这一部分，因为那些游戏所需的信息已经添加好了。

要为配置文件中定义的物件加载 GLDEFS 中定义的模型或动态光源：
要显示模型而不是物件的 sprite，或者要附加 GLDEFS 中定义的光源，GZDB 需要知道物件的类名（因为 MODELDEF 和 GLDEFS 中的覆盖就是这样定义的）。在 Doom Builder 配置文件中定义的物件没有这个值。因此，如果你使用的不是随 GZDoom Builder 提供的配置，或者你正在为 Doom 和 Doom 2 以外的游戏制作地图，你需要向游戏配置中的物件定义添加一个名为“class”的新值： 

3001
{
  title = "Imp";
  sprite = "TROOA2A8";
  class = "DoomImp"; // <- 你需要添加此值
}

你可以在 http://www.zdoom.org/wiki/Classes 找到所有物件类名。
